# bluewhale_clients

Open-source Windows and Android clients for the Bluewhale product line.

## Status

Early development. This repository currently contains project documentation only; there is no source code, build system, or test suite yet. The technology stack and project layout have not been decided.

## Scope

This repository is intended to contain the Windows and Android client applications. Shared, platform-independent logic is expected to live in the separate `bluewhale_core` repository and should be reused rather than duplicated.

## Licensing

The project is intended to be open source. A license has not been selected yet, so no license is granted at this time. Licensing will be recorded before the repository is published or external contributions are accepted.

## Contributing

Contribution guidelines and the development workflow will be added with the initial implementation. Contributions are not being accepted yet.
