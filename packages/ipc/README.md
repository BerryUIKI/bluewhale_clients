# IPC package

Generated TypeScript bindings and the typed client for Tauri commands.

- `src/bindings.ts` is generated by tauri-specta from the Rust command
  signatures in `clients-ipc`. Regenerate it with
  `cargo run -p clients-ipc --bin export_bindings`; do not edit it by hand. A
  Rust test fails when the committed file drifts.
- `src/client.ts` unwraps the result-mode responses into values or an
  `IpcError` with a stable code and a message key. A framework failure outside
  the desktop application becomes the `unavailable` code so the interface can
  explain that the desktop runtime is missing.
- `src/index.ts` re-exports the generated types and the client helpers used by
  the interface.

The bindings are imported by the shared interface, which maps error codes to
localized messages and never displays raw Rust or framework text.
